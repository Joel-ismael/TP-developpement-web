# TP-developpement-web
Ce projet est une API REST robuste permettant de gérer un système de blog (création, lecture, modification, suppression et recherche d'articles). Il a été conçu avec une architecture modulaire respectant les principes MVC (Modèle-Vue-Contrôleur). Installation et Démarrage1. PrérequisNode.js (v18.0.0 ou supérieur)MongoDB (Installé localement sur le port 27017)2. InstallationClonez le projet, puis installez les dépendances nécessaires :Bashnpm install express mongodb
3. Lancement du serveurBashnode app.js
Le serveur sera accessible sur http://localhost:3000/api.  Structure du Code & Fonctionnement Connexion Base de Données (bd/connect.js)Ce module assure la communication avec MongoDB.Gestion du client : Utilise une variable globale client pour éviter de recréer une connexion à chaque requête (Singleton).Fonction connecter : Établit le lien avec MongoDB au démarrage de l'application.Fonction bd() : Expose l'accès à la base de données nommée dbok. Modèle (model/article.js)Définit la structure d'un article de blog :Champs : Titre, contenu, auteur, catégorie, tags.Date automatique : La date de création est formatée en YYYY-MM-DD dès l'instanciation de la classe. Contrôleur (controller/article.js)Contient la logique métier pour chaque action :Validation : Vérifie la présence des champs obligatoires (titre, auteur, contenu).Filtrage : Permet de récupérer des articles par catégorie, auteur ou date via des paramètres de requête.Recherche : Utilise l'opérateur $regex de MongoDB pour trouver des mots-clés dans les titres ou les contenus (insensible à la casse). Routage (router/article.js)Organise les points d'accès de l'API :Regroupe les routes par chemin pour une meilleure lisibilité.Sépare la route spécifique de recherche (/search) des routes standards. Documentation des EndpointsArticlesMéthodeURLDescriptionPOST/api/articlesCréer un nouvel article.GET/api/articlesLister tous les articles (filtres optionnels via ?categorie=, ?auteur=, ?date=).GET/api/articles/:idRécupérer un article spécifique par son ID.PUT/api/articles/:idModifier un article existant.DELETE/api/articles/:idSupprimer un article.RechercheMéthodeURLDescriptionGET/api/articles/search?query=...Recherche un texte dans les titres et contenus.Technologies UtiliséesExpress.js (v5.2.1) : Framework web minimaliste et flexible.MongoDB Driver (v7.1.0) : Driver officiel pour interagir avec la base de données NoSQL.
